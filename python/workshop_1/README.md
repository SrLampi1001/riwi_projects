# Python Workshop 
Riwi assigment. 18 exercises completed.

## requirements
- Solve all 18 exercises
    - A function that asks two numbers and outputs the biggest one.
    - A function that asks user for age, print if it's adult or not
    - A function that asks a number, outputs if it's positive, negative or zero.
    - A function that asks user for number from 1 to 7 and shows corresponding week day. 
    - A function that asks three numbers and prints the biggest
    - A function that asks a letter, outputs "vowel" or "consonant"
    - A function that asks a password and loops until user inputs "python123"
    - A function that adds all numbers from 1 to 100.
    - A function that asks number and shows it's multiplication table to 10.
    - A function that asks the user 5 numbers and shows which are even and odd.
    - A function that asks user numbers until user inputs 0 and shows total sum.
    - A function that asks number among 0-5 and returns if it's a passing grade (>=3) or not.
    - A function that asks the actual year, birth year and calculates age.
    - A function that receives a string and returns it backwards.
    - A function that asks a number and shows all odd numbers until that one.
    - A funciton that counts the amount of letter "a" in a string
    - A function that asks user for numbers until the user inputs "fin" and shows average.
    - A function that asks the user a string and determines if it's palindrome

### Note
The exercises are executed one after the other, consecutively.
