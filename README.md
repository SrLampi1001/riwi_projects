## Activity Description:
You are a Software engineer in charge of replicating the Clipboard product landing page. This web page must transmit clearly and visually attractive the product characteristics, besides adapting to all kind of resolutions.  
### Requirements:  
#### HTML structure:
- Create an Index.html file with a semantic structure using tags like header\> , main\> , section\> , footer\>  
- Include sections equivalent to the ones in the proposed design: hero, features, workflow, partners, call-to-action and footer.  
#### CSS styles:
- Use an external file styles.css to apply all the styles
- Incorporate typographies from Google Fonts (based on the design)
- Use color palette, spaces y visual hierarchy based on the original design
- Apply visual effects like hover on buttons, links y cards
#### Responsive design:
- Implement responsive design using Flexbox and/or CSS Grid  
- Guarantee that the site is visible in:
    - Desktop (≥ 1024px)
    - Tablet (≥ 768px)
    - Phone (≤ 480px)

### Optional:  
- Create an additional version with various pages: For example, an independent page for services or features.
- Use CSS variables (:root) to define colors and fonts.
- Add smooth transitions (transition) in interactive elements like buttons and links.
- Include an animation or optional micro interaction optional in the navigation bar or buttons.
- Deploy in a public production URL.
