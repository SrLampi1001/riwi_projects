# User Story 5 (Module 3 - 2)

## Project Overview

This project demonstrates the use of JavaScript data structures including Set, Map, and Objects. It includes a `Productos` class with a static ID counter and examples of iterating over object properties using `for...in` and `for...of` loops.

The project showcases:
- Object property iteration with `for...in`
- Set operations: add, delete, has, and iteration
- Map operations: set, get, delete, has, and iteration
- Object utility methods: `Object.keys()`, `Object.values()`, `Object.entries()`

## Installation

1. Clone the repository:
```bash
git clone --branch project/web/user_story_5 --single-branch https://github.com/SrLampi1001/riwi_projects.git
```

2. Alternatively, download the `.zip` file and extract it.

## Usage

### Option 1: Browser
Open `index.html` in your web browser and open the developer tools console to see the script output.

### Option 2: Node.js
Execute the script directly with Node.js:
```bash
node gestion_datos.js
```
