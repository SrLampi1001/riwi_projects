# User Story 4 — Module 3-1

An interactive JavaScript script that greets users by name and determines if they are a minor or an adult, displaying a personalized message accordingly. The script collects user input through browser prompts, validates that age is a valid number, and shows dynamic alert messages based on the established conditions.

## What This Project Solves

- **User Interaction**: Collects user input (name and age) through browser `prompt()` dialogs
- **Input Validation**: Ensures age is a valid number using `parseInt()` and `isNaN()` with a retry loop
- **Dynamic Messaging**: Displays personalized `alert()` messages based on whether the user is under 18 or 18+
- **Error Handling**: Uses `try-catch` and `console.error()` to handle unexpected errors gracefully
- **Fundamentals Practice**: Reinforces core JavaScript concepts including variables (`let`), conditionals, data types, and user interaction methods

## Requirements

- Declare variables with `let` and `const`
- Use different data types
- Use `console.log()`, `alert()`, `prompt()`, and `console.error()`
- Use conditionals (`if`, `else if`, `else`)
- Name variables with camelCase and descriptive names
